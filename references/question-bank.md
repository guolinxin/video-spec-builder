[Purpose]
    This is a discipline tool for follow-ups, not an "inspiration bank" or survey script.
    You default to the "creative follow-up" approach; this bank is the constraint baseline — when tempted to accept vague answers, check [Unacceptable Answers];
    when tempted to stop early, check [Acceptance Criteria]; when tempted to ask randomly, check [Primary Questions].

[Discipline · Don't expose Phase labels to the user]

    Phase 1-5 are your internal tracking language, **not labels for the user**.
    Dimension section names (e.g. [1.1 · Video Purpose]) are for your internal bank lookup — don't read them aloud to the user.

    Never say to the user:
    × "OK Phase 1 locked"
    × "Entering Phase 2"
    × "Phase 4 visual fine-tuning"
    × "[Follow-up Probes] triggered"
    × "[Acceptance Criteria] gate passed"
    × "Let me unlock WebSearch to look that up for you"

    Correct approach: director-style conversational tone, **bridge topics naturally**.
    When a topic is done, recap key points in one line ("Got the fundamentals / assets are clear"),
    then naturally lead to the next topic ("Now let's talk assets" / "Next let's talk visual style").
    Transition phrasing examples at each Phase end in [Transition Phrasing Examples].

[Five-part structure · every dimension follows this]

    [Coverage Intent]      Why ask this dimension (prevent "asked without knowing why")
    [Primary Questions]    Default questions to ask user (prevent "asking from memory")
    [Follow-up Probes]     Pushback when user is vague, format "user says X → you reply Y" (prevent "accepting vagueness to be polite")
    [Acceptance Criteria]  Gate pass conditions (prevent "self-satisfied early stop")
    [Unacceptable Answers] Sample answers that must be rejected (prevent "fabricating reasonable answers")

[Progressive follow-up]
    - Phase 1 is a gate — all must have answers, but answers can be extracted from user's initial description and confirmed
    - User's answer to one question "overflows" and covers the next → absorb directly, don't ask again
    - Phase 2-5 dynamically trimmed based on Phase 1 answers (product demo focuses on 3D + UI mock,
      skip irrelevant dimensions like "3D scene type" for product demos)

[Phase 1 · Video Fundamentals]
    Phase 1 is the foundation. If the foundation cracks, the other 4 Phases are quicksand. Every dimension must reach concrete answers — no skipping.

    [1.1 · Video Purpose]
        [Coverage Intent]
            A video without purpose is a diary for yourself. Purpose determines the whole piece's tradeoffs —
            without this gate, all later judgments have no reference frame.

        [Primary Questions]
            - What problem does this video solve? What should viewers remember? What should they do?
            - Is this explainer / marketing / tutorial / product demo / brand / documentary? Mixed doesn't count — pick the dominant one.
            - After watching, what specific action should the user take? Click a link? Remember a concept? Share? Download? Sign up?

        [Follow-up Probes]
            - User says "want it to go viral" → you reply: "What's the bar for viral? Views, likes, conversion rate, or industry buzz? Give me a number."
            - User says "explainer + marketing" → you reply: "Pick one dominant. If you can only keep one purpose, which do you keep? Would cutting the other make the video not work?"
            - User says "help people learn something" → you reply: "Learn what specifically? A term's definition? A step-by-step method? A judgment criterion? Name one."
            - User says "raise brand awareness" → you reply: "How would users vote with their feet after awareness rises? Search your brand? Revisit your site? Attitude change when your brand is mentioned?"
            - User says "content archive" → you reply: "Archive for whom? Investors? Candidates? Existing users? New users? These three audiences want completely different things."
            - User says "just make it first" → you reply: "What standard judges success or failure afterward? No standard, don't make it."

        [Acceptance Criteria]
            - One sentence can state "what type + what audience remembers + what to do after watching"
            - Example: Product demo video — SaaS product managers remember "our AI auto-writes PRDs", go sign up for free trial on site
            - Example: Brand documentary — design community remembers "our founder came from industrial design to AI", willing to share video in peer groups

        [Unacceptable Answers]
            - "Either works / up to you / haven't decided" → keep probing
            - "Want viral / break out / premium / look professional" → these are outcomes not purpose, probe the concrete goal behind
            - "Content matrix" / "for content archive" → no specific audience isn't archive, it's self-indulgence
            - "Marketing + brand + explainer" three-in-one → cut to one, mixed doesn't count

    [1.2 · Target Audience]
        [Coverage Intent]
            "For everyone" equals "for no one." Audience persona determines narration language, information density, pacing —
            without this gate, all expression decisions lack direction.

        [Primary Questions]
            - Draw one specific person. Age, job, city, when do they watch this video?
            - Why would they watch? Ad served to them? Friend shared? Searched for what? Which account did they scroll from?
            - Have they seen similar content? If yes, what style? How did they feel after?

        [Follow-up Probes]
            - User says "young people" → you reply: "18-year-old intern and 32-year-old PM are both young — 14 years apart. Pick one."
            - User says "everyone" → you reply: "Everyone = no one. One video in one specific scenario for one specific person. Name one scenario, one person."
            - User says "technical people" → you reply: "How technical? Transformer needs no explanation? Attention needs explanation? Name a concrete bar."
            - User says "B2B customers" → you reply: "Which B2B role? Decision maker (CXO), user (frontline), procurement (IT)? These three care about different things."
            - User says "investors + users + internal team all watch" → you reply: "These three want three different videos. Pick one primary audience; others watch or don't."
            - User says "don't know who'll watch" → you reply: "Then why make it? Video without target audience is a diary for yourself, not content for others."

        [Acceptance Criteria]
            - Can describe one concrete persona: age range / job / industry / viewing scenario / what they're thinking before / how they feel after
            - Example: 32-year-old PM at SaaS company, sees it scrolling Xiaohongshu, usually tortured by PRD writing, after watching thinks: AI can write PRDs for me, let me try

        [Unacceptable Answers]
            - "Everyone / anyone interested" → no target = no video
            - "Experts / non-experts" → that's a spectrum, not an answer
            - "Depends on personal taste" → then why are you making this video?

    [1.3 · Platform & Duration]
        [Coverage Intent]
            Different platforms have completely different hard constraints (vertical/horizontal, duration caps, mute rate).
            Without platform and duration first, all pacing, text size, subtitle strategy can't land.

        [Primary Questions]
            - Primary distribution platform? Douyin, Xiaohongshu, Bilibili, WeChat Channels, YouTube, Twitter/X, LinkedIn, site homepage, product page embed, sales deck?
            - Duration cap? Hard cap (platform limit) and soft cap (longest you're willing to go).
            - Aspect ratio: 16:9 landscape, 9:16 vertical, 1:1 square, other?
            - Frame rate: 24 / 30 / 60?
            - Need mute-friendly playback (users scroll muted by default, rely on subtitles)?

        [Follow-up Probes]
            - User says "post everywhere" → you reply: "What's the main battlefield? Multi-platform = landscape, vertical, square versions — duration and narrative rhythm all differ. Pick main battlefield first."
            - User says "no duration limit" → you reply: "Bilibili can do 10 minutes, Douyin users swipe at 1 minute. 'No limit' means you haven't thought it through. Give me a cap."
            - User says "decide based on results" → you reply: "Your render fps isn't set — how do you start? 30fps or 60fps? 60fps doubles render time."
            - User says "vertical" → you reply: "Vertical means big-type posters, keyword highlights, 70% center height to avoid UI overlap. Accept these constraints?"
            - User says "15 seconds" → you reply: "15 seconds fits 4-6 hook-paced shots, 2-3s each. That's Douyin viral rhythm. Does your content fit?"
            - User says "about 3 minutes" → you reply: "Be precise. 180s vs 200s vs 240s are three narrative densities. Pick one."

        [Acceptance Criteria]
            - Know: main platform / duration (5-second precision) / aspect ratio / frame rate / mute-friendly or not
            - Example: Primary Xiaohongshu, vertical 9:16, 60s, 30fps, mute-friendly (must have word-by-word subtitles)

        [Unacceptable Answers]
            - "Post everywhere / multi-platform" → pick main battlefield
            - "No limit / see how it goes" → no
            - "Default is fine" → which default? Platform default or yours? Be specific

    [1.4 · Core Message]
        [Coverage Intent]
            Prevent "finished video and user doesn't know what it was saying" — one-sentence takeaway is the anchor for the whole piece.

        [Primary Questions]
            - In one sentence: after this video, what should the user remember?
            - Cut to ≤ 12 characters. Extra words are filler.
            - Is this sentence the hook or the close? Or threaded start to finish?

        [Follow-up Probes]
            - User says "our product is amazing" → you reply: "Amazing is outcome not message. Name one concrete capability: write PRDs? edit images? analyze data? Pick one."
            - User says "AI makes design easier" → you reply: "Easier for whose design? How easier? What steps saved? Give a comparison."
            - User wrote 30 characters → you reply: "Cut to 12. Which words can you cut and video still works? Which words cut and video collapses?"
            - User says "our core belief is XX" → you reply: "Belief is abstract — turn it into a slogan printable on a T-shirt. One sentence."
            - User gave three sentences → you reply: "Three sentences = three videos. Pick one; other two appear in script but aren't the main message."
            - User says "can't say it in one sentence" → you reply: "Can't finish means information not converged. One video carries one core message; rest is support."

        [Acceptance Criteria]
            - One core message ≤ 12 characters
            - This sentence works as big-type poster headline
            - Examples: "AI writes your PRD in 10 min" / "We reinvented SaaS billing" / "Design to frontend code in one click"

        [Unacceptable Answers]
            - "Our vision is to change the world" → too vague, cut to concrete
            - Over 12 characters → cut
            - "Viewer understands on their own" → you won't write one sentence — why should they spend 60 seconds watching?

    [1.5 · Information Density]
        [Coverage Intent]
            Rhythm density determines script word count, shot count, asset scale.
            Without density first, asset inventory and script writing have no reference line.

        [Primary Questions]
            - What pacing is this video?
                1. **Hook-style** (0.8-2s per cut): Douyin viral rhythm, new info every second, rhythm holds attention
                2. **Tutorial-style** (2-5s per cut): Explain each step clearly, give viewer reaction time, can follow along
                3. **Documentary-style** (3-8s per cut): Let visuals breathe, negative space, emotional setup
            - Density + duration reverse math: 60s hook = 30-60 shots; 3min tutorial = 36-90 shots. Can your assets support that?

        [Follow-up Probes]
            - User says "fast pace" → you reply: "0.8s per cut or 1.5s per cut? Two kinds of fast. Do you have content for every shot?"
            - User says "look more premium" → you reply: "Premium = slow + negative space + big type. But slow pacing requires every frame to hold up. Do your assets?"
            - User says "beat-sync editing" → you reply: "Sync to BPM drum hits or narration stress? Two different timecodes. Be specific."
            - User says "medium pace is fine" → you reply: "Medium is filler. Give a number: average seconds per shot? 2s vs 3.5s vs 5s — three different feels."
            - User says "make it and see" → you reply: "Pacing determines script word count. 60s hook fits only 90-130 chars narration. Script done yet?"

        [Acceptance Criteria]
            - Selected one primary rhythm: hook / tutorial / documentary
            - Know approximate shot duration (0.5s precision)
            - Example: hook-style + avg 1.5s per shot, 60s video ≈ 40 shots

        [Unacceptable Answers]
            - "Your call / medium / depends on assets" → decide now, pacing determines script word count
            - "A bit faster / a bit slower" → relative words, give absolute values

    [1.6 · Brand Tone of Voice]
        [Coverage Intent]
            Video without tone anchor — narration and copy feel personality-less, "machine-heavy."

        [Primary Questions]
            What's the video's "vibe"? Serious / humorous / self-deprecating / authoritative / ironic / calm / passionate?
            Pick 1-2 dominant + 1 absolute no-go opposite.

        [Follow-up Probes]
            - User says "professional" → you reply: "Professional has many flavors. TED speaker 'gentle authority'? Apple Keynote 'sacred'? McKinsey 'data-calm'?"
            - User says "humorous" → you reply: "Knowing smile, big laugh, or dry smirk? Humor granularity differs a lot."
            - User says "young and energetic" → you reply: "That's outcome not tone. Specifically Douyin internet-native, Bilibili anime, or Gen Z irony?"

        [Acceptance Criteria]
            Can anchor tone with 1-2 concrete "reference personas" (e.g. "TED speaker + a bit of Karpathy self-deprecation")

        [Unacceptable Answers]
            - "Professional / premium / young / energetic" → these are outcomes not tone
            - "Up to you" → user must decide

    [1.7 · Audience Familiarity]
        [Coverage Intent]
            Video assuming jargon by default repels beginners;
            video explaining basics bores insiders.
            Must set onboarding depth first.

        [Primary Questions]
            Target audience familiarity with the topic?
            - Complete beginner (start from "what is this")
            - Heard of it but don't know details (start from "why it matters")
            - Industry insider (go straight to "what's new", don't explain terms)

        [Follow-up Probes]
            - User says "ordinary people" → you reply: "Ordinary differs. Subway scrollers vs product-page searchers — completely different familiarity."
            - User says "technical people" → you reply: "How technical? Know what RAG is? Cosine similarity? Reranker? Test user's knowledge floor."

        [Acceptance Criteria]
            Can state boundary: "terms user 100% knows + terms user 100% doesn't know"

        [Unacceptable Answers]
            - "Everyone will understand" → impossible
            - "I guess they probably know" → guessing doesn't count

    [Transition Phrasing Examples · Fundamentals done → start talking assets]
        After this section's dimensions are complete, recap key points in bridging conversational tone, naturally lead to assets topic.
        Don't use "switching to next stage", "Phase 1 locked", "entering Phase 2".

        ✓ "Good, I've got your video fundamentals — [recap purpose/audience/platform/duration/core message key items]. Now let's see what assets you have on hand."
        ✓ "OK, fundamentals clear. Let's talk assets — do you have a full script? BGM? Video clips?"
        ✓ "Got it, [one-sentence video positioning summary]. Let's inventory assets, starting with the script."

        Never:
        × "Phase 1 locked"
        × "Entering Phase 2 asset inventory"
        × "After these two → Phase 2"
        × "OK got it, unlocking next stage"

[Phase 2 · Asset Inventory]
    Inventory existing assets item by item — must ask about anything user didn't mention, otherwise you're fabricating content.

    [2.1 · Content Assets]
        [Coverage Intent]
            Script is the video's code. Without full script and data sources, you'll fabricate numbers and cases.
            "Close enough" in a video is an incident.

        [Primary Questions]
            - Full narration script? Outline? Selling-point list? Or just an idea?
            - Specific numbers, data, cases, quotes appearing in video — all available? Sources?
            - Testimonials, client logos, awards, media quotes — these "trust anchor" assets available?

        [Follow-up Probes]
            - User says "I have a rough script" → you reply: "Rough = none. Send full script, or we write now. Script is video's code — no script is LEGO without instructions."
            - User says "number is roughly XX%" → you reply: "XX% or XX.5%? Wrong number on screen is an incident. Where's the source?"
            - User says "I'll figure it out on the spot" → you reply: "On the spot = you accept AI improvisation then redo. Either write now or accept AI draft then you review."
            - User says "lots of selling points" → you reply: "List them, priority order. Top 3 in video, rest cut."
            - User says "our clients include XX, YY, ZZ" → you reply: "Logo authorization? Unauthorized logos can't appear — that frame is legal risk."

        [Acceptance Criteria]
            - Full narration script (or confirmed you'll write script then human review)
            - All numbers/data in video have sources
            - Client logos/cases confirmed for use rights

        [Unacceptable Answers]
            - "Roughly" / "close enough" → can't be close enough on video
            - "You make it up" → OK to draft, but you must review — AI numbers without review going live is an incident

    [2.2 · Audio Assets]
        [Coverage Intent]
            Narration source (live / TTS / none) directly determines whole production workflow and timeline.
            BGM rhythm determines edit beat-sync. Without audio path first, all timecodes lack baseline.

        [Primary Questions]
            First inform capability: "Render pipeline has built-in local TTS (no API key, free, purely local. Specific model / supported voice IDs / language count → I'll check render docs or search latest version.)"
            Then ask:
            - How to handle narration? Three options:
                1. **Live recording** (you or colleague records, send wav/mp3)
                2. **Local TTS** (direct config)
                3. **No narration** (text + music only)
            - Background music: licensed (Epidemic Sound / Artlist) or royalty-free (YouTube Audio Library)? Or none?
            - Sound effects (whoosh, click, ding) — using any?

        [Follow-up Probes]
            **(a) TTS path**
                - User says "use AI voice" → you reply: "What language? Available voice IDs I'll check render docs (or pull latest list online). Pick one or I'll list candidates."
                - User says "Chinese voiceover" → you reply: "Local TTS Chinese generally less natural than English (common for Chinese TTS). Mind it? If yes, consider live recording + post mix."
                - User says "GPT-style voice" → you reply: "Local TTS: no API key, free, no network requests. Dozens of iterations with local TTS is painless; one-shot extreme quality consider ElevenLabs / similar cloud TTS, but separate integration. Pick a path."
                - User says "normal speed" → you reply: "Local TTS default 1.0, tutorial usually 0.7-0.8, marketing 1.1-1.2. Which is this video?"

            **(b) Live recording path**
                - User says "I'll record" → you reply: "Recording environment room or studio? Room reverb needs post noise reduction."
                - User says "I'll record Chinese myself" → you reply: "Send wav not mp3 after recording — lossless for mixing."
                - User says "hire voice actor" → you reply: "Already hired? If not, finding actor to delivery usually 3-7 days — confirm timeline enough."

            **(c) Background music**
                - User says "use motivational music" → you reply: "Motivational = what BPM? 120 or 140? Determines edit beat-sync rhythm."
                - User says "you pick" → you reply: "I can recommend 3 from Epidemic Sound, but you need account to download. Have one? If not use YouTube Audio Library."
                - User says "no background music" → you reply: "Voice + ambient only works, but confirm narration audio is clean. Again: rhythmic video without BGM feels bare."

        [Acceptance Criteria]
            - Narration path set: live / TTS (with voice ID, specific ID from render docs) / no narration
            - BGM source set (specific track or confirmed you'll recommend)
            - SFX yes/no decided

        [Unacceptable Answers]
            - "Default is fine" → which default?
            - "Wait until I record" → then wait to make video, stop now

    [2.3 · Video / Footage Assets]
        [Coverage Intent]
            Live action / B-roll / Lottie are three completely different footage types,
            each with different copyright, matting, loop rules. Missing any category means rework later.

        [Primary Questions]
            First inform capability: "Can use u2net local matting to generate VP9 alpha WebM for 'text behind person' transparent overlay (text-behind-subject), one command, no green screen."
            Then ask:
            - Live-action footage? (you explaining, client testimonial, vlog style, demo operation)
            - B-roll footage? (product shots, work scenes, city, nature) — licensed (Pexels / Pond5 / self-shot) or need to search stock?
            - Existing Lottie animation files (.json)?

        [Follow-up Probes]
            **(a) Live action**
                - User says "I have a clip of me explaining" → you reply: "How long? Resolution? Need matting in video or full-screen? If matting: solid background (green screen/white wall) or cluttered scene? u2net works on cluttered but edges may jag."
                - User says "use client testimonial" → you reply: "Client authorized? How long? Need subtitles? If yes we use transcribe auto-generate later."
                - User says "want text-behind-person effect" → you reply: "OK, use remove-background for two layers: cutout (person foreground transparent) + plate (background transparent, person area cut out). Text sandwiched. Original video can't have fast movement or edges break. OK?"

            **(b) B-roll**
                - User says "use some tech-feel footage" → you reply: "Tech-feel is dystopia neon? Silicon Valley minimal? NASA control room? Three completely different."
                - User says "I'll find on Pexels" → you reply: "Find first then decide. Pexels sometimes far from what you imagine — find before locking rhythm."
                - User says "no B-roll" → you reply: "Then this video is pure text + data + charts. Can do, but visuals rely on layout and motion. Accept?"

            **(c) Lottie**
                - User says "have Lottie" → you reply: "How many? What animations? Duration? Loop or once? repeat: -1 not allowed — loop count = Math.ceil(duration / cycleDuration) - 1."
                - User says "no Lottie but want it" → you reply: "Lottie needs After Effects + Bodymovin — separate workflow. Time enough this round? If not use CSS/GSAP animation."

        [Acceptance Criteria]
            - Live-action list: filename / duration / resolution / matting or not
            - B-roll list: source / count / duration / downloaded or not
            - Lottie file list: path / duration / loop rules

        [Unacceptable Answers]
            - "I have some footage" → list them
            - "I'll go find some" → find before starting, otherwise fabricating

    [2.4 · Graphic Assets]
        [Coverage Intent]
            Illustrations, logos, fonts are magnified many times in video — "use whatever" equals "use whatever blurry."
            Wrong font format, unauthorized logo both block production directly.

        [Primary Questions]
            First inform capability: "Doesn't support .ttf or .otf — fonts must be .woff2 (in fonts/ directory, compiler auto-embeds)."
            Then ask:
            - Illustration assets? (SVG vector, PNG, AI / Figma files) Send if yes.
            - Photo assets? Product shots, team photos, scene photos.
            - Logo? SVG or high-res PNG. Transparent background.
            - Custom fonts? .woff2 files.

        [Follow-up Probes]
            **(a) Illustrations**
                - User says "I have some SVGs" → you reply: "How many? Decorative or narrative? Decorative (background texture) vs narrative (step icons) handled differently."
                - User says "use Notion-style illustrations" → you reply: "Notion's own illustrations are copyrighted assets — can't use. Want similar style, use unDraw or Storyset."
                - User says "use emoji" → you reply: "Emoji looks different on different OS — render pitfalls. Recommend SVG emoji (Twemoji is open source). Accept?"

            **(b) Logo**
                - User says "logo is in PPT" → you reply: "PNG or vector in PPT? Send SVG or high-res PNG (≥ 1000px). Low-res blurs in video."
                - User says "use client logo wall" → you reply: "How many? Authorized? Unauthorized logos can't appear — even if placed, must mosaic."

            **(c) Fonts**
                - User says "use Source Han Sans" → you reply: "Provide .woff2, at least weights theme needs (specific tiers from theme, validated at render). Full set?"
                - User says "no fonts" → you reply: "After theme selection use theme bundled fonts (each theme differs — presets in HyperFrames visual-styles.md, custom in project root design.md). Unless strong brand need, follow theme."
                - User says "use brand font XX" → you reply: "Licensed? Many commercial fonts are seat subscriptions — video distribution may need commercial license. Confirmed?"

        [Acceptance Criteria]
            - Graphic asset list: every item has file path and purpose
            - Font file list: .woff2 paths + weight list

        [Unacceptable Answers]
            - "I'll ask designer" → get them before starting
            - "Just use any" → every asset magnified 10× in video — "any" equals "blurry"

    [2.5 · 3D Assets & Special Visuals]
        [Coverage Intent]
            3D / Shader / audio-reactive are "capability selling points" — users won't ask for what they don't know exists.
            Missing these = expression toolkit artificially halved.

        [Primary Questions]
            First inform capability:
            - Have 3D models? GLTF / GLB format works directly, Three.js loads.
            - Need HDRI environment map (real reflections on 3D objects)?
            - Want Three.js procedural geometry (particle systems, wireframe, morphing spheres)?
            - Want shader transitions (WebGL advanced transitions, more texture than CSS)?
            - Want audio-reactive visualization (spectrum-driven graphics)? Existing audio-reactive references supported.

        [Follow-up Probes]
            **(a) 3D**
                - User says "use 3D model" → you reply: "Model source? Blender export? Purchased? Open source (Sketchfab CC)? Licensed?"
                - User says "particle effects" → you reply: "Particles decorative or narrative? Decorative (background sparkle) Canvas 2D enough; narrative (particles form logo) needs Three.js + custom shader — 10× workload."
                - User says "wireframe style" → you reply: "Wireframe decorative background or scene protagonist? If protagonist, rotate? RPM? Slow 6s per rotation or fast 1s?"

            **(b) Shader transitions**
                - User says "want those premium transitions" → you reply: "Shader transitions are GLSL — shader-transitions package has dissolve, warp, glitch, wave. Which feel? Explosive vs soft?"
                - User says "your call" → you reply: "I can give 3 shader options, but each shader is one mood. Pre-render demos for you to pick. Accept that rhythm?"

            **(c) Audio-reactive**
                - User says "want music-rhythm effects" → you reply: "React to which audio? BGM or narration? React on which element? Font weight? Glow size? Card scale? Pick one."
                - User says "your call" → you reply: "BGM beat reaction most common. Element: hero big type letter-spacing or background ring radius. Accept this default?"

        [Acceptance Criteria]
            - Need 3D / shader / audio-reactive visualization — explicit yes/no
            - If yes, each item has concrete description

        [Unacceptable Answers]
            - "More premium / cooler" → cut to concrete effect
            - "Your call" → give options for user to pick, don't decide for user

    [2.6 · Assets to Search]
        [Coverage Intent]
            Assets marked "don't have" from inventory — either write search checklist or cut related scenes.
            Without this step, production inevitably improvises keywords and search results miss the mark.

        [Primary Questions]
            For assets marked "don't have" above — want AI to help search?
            Won't download for you, but will write "what to search, where, acceptance criteria" into video-spec.md,
            so render knows where to look.

        [Capability notice]
            "Free commercial-use assets mainly from these platforms:
            - Video B-roll: Pixabay / Pexels / Mixkit / Coverr (mostly CC0)
            - Images: Unsplash / Pexels / Pixabay
            - Music BGM: Pixabay Music / YouTube Audio Library / Uppbeat
            - SFX: Freesound / Pixabay SFX / Zapsplat
            - Fonts: Google Fonts / Adobe Fonts
            - Icons: Lucide / Heroicons / Feather Icons / Phosphor
            - Illustrations: Open Peeps / unDraw / Storyset
